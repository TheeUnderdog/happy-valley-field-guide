# Town folders

Town folders are nearest-town/community containers for event and place Markdown files. The guide is the Lenoir region as a whole, so there is no separate `area` field.

## Folder creation rule

Create a new town/community folder when a source identifies that place as the venue address, the community name is how a local/new resident would search for it, or three or more entries accumulate for a smaller community not yet represented.

## Asheville region (added by explicit user request, September 2026)

The guide originally kept Asheville out of scope as a ~50-mile radius from Lenoir. Asheville is farther out than that original boundary but is now explicitly in scope as a second full region of the guide, alongside the Lenoir/Caldwell core. Treat it the same as any other part of the guide: research, add, and maintain places/events normally, no special caution required.
